# MotionCanvas Advanced Feature References

## MIT references

- Dolphin Animate — MIT. Feature reference for classic frame spanning/tweening and path-based Motion Guides.
- tween.js — MIT. Easing-equation reference for Linear, Ease-In, Ease-Out and Ease-In-Out interpolation.

MotionCanvas uses independent Kotlin implementations of these concepts; no Dolphin Animate or tween.js source is copied into the Android project.
